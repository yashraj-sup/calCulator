# CALCULATOR
Its a calculator with digits,operators,clear and other conventional keys with keyboard support which works in your browser.
## How to run it:
open index.html in any browser you like

## Features:
- chained operations
- decimals
- backspace
- keyboard support
-  a special message "Nice try, son!" displays whenever you try to divide any digit/number by zero
